Программа принимает на вход каталог с файлами и возвращает список файлов и их дубликатов.

1. Создайте виртуальное окружение: python3 -m venv find_duplicates_environment
2. Активируйте виртуальное окружение: source find_duplicates_environment/bin/activate
3. Установите зависимости: pip install -r requirements.txt
4. Запустите программу: python3 find_duplicates.py wav_data duplicates.txt
5. Чтобы выйти из виртуального окружения, деактивируйте его: deactivate
